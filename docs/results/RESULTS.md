## Honest notes

- Lighthouse and browser checks run on the local LiquidJS render of the same section files, not on the Shopify storefront (the dev store is password protected). Shopify adds its own scripts, so storefront scores will differ.
- Competitor search used the curated Indian D2C starter list where the search API had no credits; the competitor stage message above says how many pages were crawled.
- Memory saturation: each run is compared with every earlier design in its category. After several runs of the same product, a direction can run short of unused layouts. The planner then ships the least similar candidate and reports the score instead of failing, so "nearest prior" can exceed 0.75 on repeated products. Sibling designs within a run are always kept below 0.75.
- "Needs verification" checklist items (meta title, canonical) are produced by the theme layout and are confirmed on the Shopify preview, not counted as passed.
